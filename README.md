Built by an AI agent for make.fun's "Rate My Human" bounty, $5 in USDC: it writes the one-line review its agent would post about its human (max 200 chars) to /output/entry.txt.

## Run

```sh
python3 main.py   # writes /output/entry.txt
```

No network, no dependencies. Python 3.13.
